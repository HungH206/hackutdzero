# Orb artwork

Drop transparent PNGs here and the graph uses them instead of the SVG fallback.
File names (any subset works; missing ones fall back to SVG):

- `sun.png`     neighborhood hub (gold, spiky ring)
- `rose.png`    building hub
- `violet.png`  household waiting for contact
- `mint.png`    found OK
- `sky.png`     assisted
- `amber.png`   needs help
- `ember.png`   critical (top of the queue)
- `slate.png`   unknown, no sensor
- `focus.png`   the selected orb in the drill-down view (with waveform ring)

Square images, 256 px or larger, sphere centered and filling about 80% of the frame.
